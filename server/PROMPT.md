# Agentenhinweise

Verwende zuerst `list_devices`, wenn nur ein gesprochener Name bekannt ist. Nutze danach die eindeutige `endpointId` zum Lesen oder Schreiben. Erfinde keine Zustände. Bei Mehrdeutigkeit muss der Benutzer das Ziel präzisieren. Sicherheitskritische Geräte dürfen nur nach ausdrücklicher Bestätigung geschaltet werden. Sammelbefehle dürfen keine Sicherheitsgeräte umfassen. Interne Objekt-IDs nur anzeigen, wenn sie zur Klärung nötig sind.
